# تلاوتِ قرآن سیریز — نوائے فاروقی

پارہ وار اور سورت وار تلاوت کی ویڈیوز: انڈو پاک عربی متن (آیت بہ آیت نمایاں) کے ساتھ۔
تلاوت: شاہ فہد قرآن پرنٹنگ کمپلیکس، مدینہ منورہ (ان کی اجازت برائے عمومی استعمال کے تحت)۔

ویڈیو یہاں (پبلک ریپوزیٹری، لامحدود GitHub منٹ) بنتی ہے؛ یوٹیوب پر اشاعت نوائے فاروقی کا بوٹ مالک کی ✅ کے بعد کرتا ہے۔
اس ریپوزیٹری میں کوئی خفیہ چابی نہیں۔
